# W2D1 Assignment: The High Score Tracker

### The Mission
You have been given a static array containing 5 arcade scores. Your job is to analyze this data using loops.

### Requirements
- You **must** use a `for` loop to iterate through the array. Do not hardcode the math!
- Calculate the `highestScore`.
- Calculate the `averageScore`. (Remember the `int` vs `double` trap from Week 1!)
- Do not change the line that declares the `scores` array. The auto-grader will inject different arrays to test your logic!
